## 二、已知问题与技术债

1. **弹层组件隐患**：antd 的 Dropdown / Select 仍走 rc-trigger（与之前 tooltip 失效同源），桌面端尚未实测出问题，但属于定时炸弹
2. **Mod 目录无自动迁移**：`Mods\` 改名 `Mod\` 后，老用户工作目录里的旧 `Mods\` 不会自动搬移，首次使用需手动改名
3. **死代码**：`wallpaperTint`（壁纸主色调计算）已被真实模糊取代，无消费者
4. **注入失败诊断弱**：失败时只有错误字符串，缺少可操作的排查提示

## 三、规划（按优先级）

### 近期 · 稳定性（1-2 周）

- **P1 弹层统一**：菜单 / 下拉复用 SafeTooltip 思路自绘，或降级锁定可用的 antd 版本，消除 rc-trigger 隐患
- **P1 Mod 目录自动迁移**：安装时检测旧 `Mods\` 并自动改名为 `Mod\`，兼容老用户
- **P2 注入失败自诊断**：整理常见失败原因（反作弊拦截 / 权限 / 路径含中文等），失败时给出对应排查建议

### 中期 · 功能打磨（1-2 月）

- **Mod 体检**：参考 XXMI 的 `IniValidator`（rogue d3dx.ini、hash 缺失、TextureOverride 完整性检查），安装/启用前扫描问题 ini 并给出一键修复
- **d3dx.ini 配置化**：分辨率、日志级别等常用项暴露到设置页
- **悬浮窗增强**：可拖拽布局 / 按键自定义

### 远期 · 可选方向

- **多游戏支持**：沿 XXMI 的包管理思路抽象出游戏 profile
- **mod 备份与同步**：工作目录一键导出 / 导入
